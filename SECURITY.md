# Security policy

PatchPilot is an early-stage remediation tool and has not undergone an independent security audit.

Do not report secrets, private application code or exploitable details in public issues. Use the repository's private vulnerability reporting feature if enabled, or contact the maintainer through an existing private channel.

Include the affected commit, execution phase, configuration with all secrets removed, impact and minimal reproduction. Revoke exposed credentials before sharing diagnostics.

See docs/security.md for the threat model and mandatory deployment controls.
